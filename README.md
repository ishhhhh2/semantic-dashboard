# Semantic HTML5 & Accessible Enterprise Dashboard

## Project Overview

This project is an accessible enterprise dashboard built using semantic HTML5, CSS, and JavaScript.

The project focuses on creating a clean structural foundation with accessible navigation, forms, tables, and modal dialogs.

## Features

- Semantic HTML5 structure
- Accessible header and navigation
- Dashboard sidebar
- Multiple pages
- Accessible data table
- Accessible user form
- Form validation
- Accessible modal dialog
- Keyboard navigation
- Visible keyboard focus states
- Responsive layout
- W3C HTML validation

## Pages

- Dashboard
- Users
- Reports
- Settings

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Accessibility

The project includes:

- Semantic HTML elements
- Proper heading hierarchy
- Form labels
- Fieldset and legend
- Table caption and column scopes
- ARIA labels where appropriate
- Keyboard-accessible controls
- Visible focus indicators
- Native HTML form validation
- Accessible dialog labeling

## Validation

All HTML pages were checked using the W3C Markup Validation Service and completed with no validation errors or warnings.
